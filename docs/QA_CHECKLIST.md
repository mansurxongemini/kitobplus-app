# Ручной чек-лист приёмки (QA Checklist) KitobPlus

Документ содержит обязательный чек-лист ручной приёмки веб-интерфейса KitobPlus перед каждым релизом. Приоритет проверок ориентирован на пользователей скринридеров (незрячих) и слабовидящих людей, управление только с клавиатуры и соблюдение стандартов доступности WCAG 2.2 AA / AAA.

---

## 1. Сквозные платформенные проверки

### 1.1. Экранные читалки (Screen Readers)
Необходимо провести сквозное тестирование сценариев в трёх основных связках:
- **NVDA (актуальная версия) + Firefox / Chrome (Windows):**
  - [ ] При переходе по ссылкам корректно озвучивается новый заголовок вкладки `«<Title> — KitobPlus»` и заголовок H1 или ориентир `<main>`.
  - [ ] Клавиша `H` последовательно переходит по иерархии заголовков (H1 → H2 → H3) без пропусков уровней.
  - [ ] Клавиша `D` (ориентиры / landmarks) распознает: баннер (`header`), основную область (`main id="main_content"`), подвал (`footer`) и навигацию (`nav`).
  - [ ] В списках карточек (`BookGrid`) читалка объявляет общее количество элементов и текущий номер пункта (например, «список из 12 элементов»).
  - [ ] Динамические сообщения (смена темы, размера шрифта, скорости воспроизведения, добавление закладки, число найденных книг) озвучиваются через polite live-регион `#a11y-announcer`.
- **TalkBack + Chrome (Android):**
  - [ ] Жесты смахивания вправо/влево последовательно проходят по всем интерактивным элементам страницы.
  - [ ] Двойной тап активирует кнопки, ссылки и переключатели.
  - [ ] В плеере корректно зачитываются кастомные метки слайдера времени («X минута Y секунда из Total»).
  - [ ] Мобильное меню открывается по кнопке «Меню», фокус удерживается внутри Drawer, закрывается кнопкой «Закрыть» или системным жестом «Назад».
- **VoiceOver + Safari (iOS / macOS):**
  - [ ] На iOS: ротор (Rotor) корректно выводит списки заголовков, ссылок и ориентиров.
  - [ ] Кнопка быстрой навигации «Перейти к основному содержимому» корректно переносит фокус к началу содержимого страницы.
  - [ ] Декоративные обложки (`alt=""`) игнорируются VoiceOver и не замусоривают речевой вывод.
  - [ ] На macOS (VO + стрелки) фокус не застревает в скрытых SVG или декоративных элементах.

### 1.2. Навигация только с клавиатуры (Keyboard Only)
- [ ] **Skip-link:** При первой загрузке страницы первое нажатие `Tab` показывает визуальную кнопку «Перейти к основному содержимому», нажатие `Enter` переносит фокус в `<main id="main_content">`.
- [ ] **Видимость фокуса:** Каждый интерактивный элемент (ссылки, кнопки, поля ввода, вкладки, слайдеры, пункты пагинации) имеет четкое видимое кольцо фокуса (`outline: 3px solid`, `offset: 3px`). Фокус нигде не скрыт.
- [ ] **Логичный порядок фокуса:** Фокус перемещается строго сверху вниз и слева направо в соответствии с визуальной структурой.
- [ ] **Отсутствие фокусных ловушек:** Ни в одном компоненте, выпадающем меню или модальном окне фокус не блокируется навсегда; `Escape` закрывает открытые поповеры и меню.
- [ ] **Карточки книг:** При фокусе на названии книги кольцо фокуса обрамляет всю карточку книги (`&:focus-within`), нажатие `Enter` открывает страницу книги.

### 1.3. Масштабирование: Zoom 200% и размер текста ×1.3
- [ ] **Браузерный Zoom 200%:**
  - [ ] При увеличении масштаба страницы до 200% в десктопном браузере не появляется горизонтальная полоса прокрутки на уровне окна (`overflow-x`).
  - [ ] Текстовые блоки не обрезаются и не накладываются друг на друга.
  - [ ] Шапка плавно адаптируется, при нехватке места переключаясь на кнопку «Меню».
- [ ] **Размер текста ×1.3 (`textScale: xlarge`):**
  - [ ] В меню «Вид» выбирается размер «Очень крупный» (`xlarge`).
  - [ ] Все надписи, карточки книг, поля форм и кнопки пропорционально увеличиваются.
  - [ ] Шапка автоматически переходит в режим кнопки «Меню» благодаря медиазапросу с поправкой на масштаб (`(min-width: 1280 * scale)`).

### 1.4. Три темы оформления (Light, Dark, Contrast)
- [ ] **Светлая тема (Light):**
  - [ ] Фон мягкий теплый белый (`#FBFBF9`), текст контрастный тёмный (`#0E1A2B`, 16.5:1).
  - [ ] Основные кнопки — чернильные (`#0E1A2B`), текст белый (`#FFFFFF`, 16:1).
  - [ ] Бренд-акцент Moviy (`#1D5FA8`) используется для ссылок, активных индикаторов и логотипа.
- [ ] **Тёмная тема (Dark):**
  - [ ] Фон глубокий тёмный (`#0A1019`), текст светлый (`#EEF2F8`, 17:1).
  - [ ] Основные кнопки — светлые (`#EEF2F8`), текст тёмный (`#0A1019`).
  - [ ] Акцент Moviy переключен на светлый оттенок (`#8CC2F5`, 8.9:1).
- [ ] **Высококонтрастная тема (Contrast):**
  - [ ] Фон абсолютно чёрный (`#000000`), текст идеально белый (`#FFFFFF`, 21:1).
  - [ ] Акцент и кнопки действия — ярко-жёлтые (`#FFE14D`), текст чёрный.
  - [ ] Все тени полностью отключены (`box-shadow: none`).
  - [ ] Все карточки, диалоги, поля ввода и разделители имеют контрастные рамки толщиной 1.5–2px (`border: 2px solid #FFFFFF`).
  - [ ] Текстовые ссылки подчёркнуты (`text-decoration: underline`).
  - [ ] Картинки и обложки получают фильтр лёгкого контраста.

### 1.5. Мобильный экран 390px
- [ ] Тестирование на ширине вьюпорта 390px (типичный мобильный экран):
  - [ ] Отсутствует горизонтальный скролл страницы.
  - [ ] Кнопка мобильного меню в шапке доступна и легко нажимается (размер touch-target не менее 48×48px).
  - [ ] В форме входа кнопка Google Sign-In не выходит за границы карточки (тянется на 100% ширины контейнера).
  - [ ] Сетка книг перестраивается в 2 колонки (`columns.xs = 2`), отступы комфортны для чтения.
  - [ ] Элементы плеера на странице книги компактно группируются, слайдер громкости аккуратно скрывается на малых экранах, оставляя управление системным кнопкам звука.

### 1.6. Режим уменьшения движения (`prefers-reduced-motion`)
- [ ] При включении в операционной системе режима уменьшения движения (Reduced Motion):
  - [ ] «Дышащая» звуковая волна в герое главной страницы замирает в статичном плавном положении.
  - [ ] Анимированные столбики логотипа-эквалайзера (`LogoMark`) останавливаются.
  - [ ] Компоненты `<Reveal>` отображаются мгновенно без анимации сдвига `translateY` и прозрачности `opacity`.
  - [ ] Слова заголовка в `<RiseText>` отображаются сразу целиком.
  - [ ] Переход «обложка летит на страницу книги» мгновенно открывает страницу без View Transitions и без анимации движения.
  - [ ] Плавный скролл страницы отключается (`scroll-behavior: auto !important`).

## 2. Постраничные проверки доступности и сценариев (`web/src/App.js`)

### 2.1. Главная страница (`/`, `HomePage`)
- [ ] **Заголовок вкладки и фокус:** Заголовок страницы — `Главная — KitobPlus`. При переходе фокус перемещается в `<main id="main_content">`.
- [ ] **Главный заголовок H1:** Озвучивается фраза «Книги теперь звучат.» (`#kp-hero-title`), акцентное слово «звучат» оформлено курсивом с засечками (`<Accent>`).
- [ ] **Ориентиры (Landmarks):** На странице присутствуют `<header>`, `<main id="main_content">`, `<footer>`, а также логические секции с уникальными `aria-labelledby`:
  - `section aria-labelledby="kp-hero-title"` (Герой)
  - `section aria-labelledby="kp-shelf-title"` (Полка недели)
  - `section id="about" aria-labelledby="kp-about-title"` (О нас)
  - `section aria-labelledby="kp-genres-title"` (Жанры)
  - `section aria-labelledby="kp-access-title"` (Доступ к библиотеке)
  - `section aria-labelledby="kp-features-title"` (Удобство без зрения)
  - `section aria-labelledby="kp-news-title"` (Новости)
  - `section aria-labelledby="kp-join-title"` (Призыв к регистрации)
- [ ] **Кнопка прослушивания отрывка («Живой голос»):**
  - [ ] Кнопка содержит состояние `aria-pressed="false"` (в покое) и `aria-pressed="true"` (во время воспроизведения).
  - [ ] Текст кнопки переключается: «Послушать 10 секунд» → «Остановить». Отображается название и автор книги дня.
  - [ ] **Речевое объявление:** При старте отрывка скринридер озвучивает: `«Звучит отрывок: <Название книги>»`.
  - [ ] **Клавиатурный хоткей:** Нажатие клавиши `Space` (когда фокус находится на странице вне полей ввода) запускает и останавливает отрывок.
  - [ ] **Fallback:** Если аудиофайл отрывка недоступен, срабатывает синтез речи `speechSynthesis` с зачитыванием названия и аннотации на узбекском языке.
- [ ] **Полка недели (`Shelf`):**
  - [ ] Вкладки подборки размечены как `Tabs aria-label="Подборка книг"`, переключаются стрелками клавиатуры.
  - [ ] Контейнер книг имеет `role="tabpanel"`.
  - [ ] Сетка книг `BookGrid` размечена как `ul aria-label="Последние" / "Популярные"`.
- [ ] **Секция жанров:** Ссылки ведут на `/person/genres/:id`, при наведении стрелка плавно сдвигается, текст меняет цвет на `primary`.
- [ ] **Фирменные карточки доступа:** Кнопка «Подтвердить статус» и кнопка «Попробовать бесплатно» ведут в `/profile` (для авторизованных) или в `/login`.

### 2.2. Каталог аудиокниг (`/books`, `/books/:table/:id`, `Books`)
- [ ] **Заголовок и крошки:** Заголовок вкладки — `Аудиокниги — KitobPlus`, H1 — `Аудиокниги`. Хлебные крошки: «Главная» → «Аудиокниги» (`aria-current="page"`).
- [ ] **Поиск (`Filter`):**
  - [ ] Поле ввода поиска доступно по Tab, имеет видимую подпись и плейсхолдер.
  - [ ] Ввод текста синхронизируется с URL-параметром `?q=...` без полной перезагрузки страницы.
  - [ ] Очистка поля сбрасывает параметр в URL.
- [ ] **Сортировка и фильтрация:**
  - [ ] Параметры сортировки (`BooksViewParams`) позволяют выбрать порядок («Сначала новые», «Популярные» и др.).
  - [ ] Фильтр жанров (`GenresSelector`) содержит интерактивные чипы; выбранные жанры имеют статус активности.
- [ ] **Живое речевое объявление результатов:**
  - [ ] При каждом изменении поисковой строки, сортировки, смене выбранного жанра или номера страницы скринридер объявляет через live-регион: `«Найдено книг: <число>»`.
- [ ] **Список результатов (`BooksSection`):**
  - [ ] Область результатов размечена как `role="tabpanel" aria-busy="true"` во время выполнения сетевого запроса.
  - [ ] При загрузке отображаются ровно 12 карточек-скелетонов (`BookCardSkeleton`).
  - [ ] Карточки книг отображаются списком `<ul>/<li>`. Каждая карточка содержит единственную ссылку на названии книги, растянутую на всю карточку.
- [ ] **Состояние «Ничего не найдено»:**
  - [ ] Если книг не найдено, отображается иконка, заголовок H3 «Ничего не найдено», пояснение и крупная кнопка «Сбросить фильтры».
  - [ ] Нажатие кнопки «Сбросить фильтры» очищает строку поиска, выбранные жанры и возвращает сортировку к значению по умолчанию.
- [ ] **Пагинация (`BooksPagination`):**
  - [ ] Каждая кнопка страницы озвучивается скринридером: «Текущая страница N» (для выбранной), «Перейти на страницу N» (для невыбранных).
  - [ ] Кнопки навигации озвучиваются как «Предыдущая страница», «Следующая страница», «Первая страница», «Последняя страница».
  - [ ] При переходе на другую страницу страница плавно прокручивается к началу списка результатов.

### 2.3. Страница книги с аудиоплеером (`/books/:id`, `Book`)
- [ ] **Заголовок и фокус:** Заголовок вкладки — `«<Название книги> — KitobPlus»`. Заголовок H1 (`#book-title`) имеет `tabIndex={-1}` и получает программный фокус после завершения перехода.
- [ ] **Обложка и View Transition:** Обложка книги имеет `alt=""`, имя перехода `kp-cover-<id>` и при переходе из каталога плавно занимает позицию в шапке книги.
- [ ] **Кнопка книжной полки:** Кнопка озвучивает текущий статус: «Поставить на книжную полку» или «Снять с книжной полки».
- [ ] **Аудиоплеер (`AudioPlayerSection`):**
  - [ ] **Ориентир:** Карточка плеера имеет `role="region" aria-label="Слушать: <Название книги>"`.
  - [ ] **Скрытая инструкция для скринридеров:** Присутствует элемент `<VisuallyHidden id="player-shortcuts-hint">` с текстом: *«Сочетания клавиш плеера. Пробел — воспроизведение или пауза. Стрелки влево и вправо — назад или вперёд на 30 секунд. Стрелки вверх и вниз с Shift, а также клавиши < и > — скорость.»*.
  - [ ] **Горячие клавиши плеера (когда фокус вне полей ввода):**
    - [ ] `Space` — запуск воспроизведения или пауза (если фокус не на другой интерактивной кнопке).
    - [ ] `Escape` — постановка воспроизведения на паузу.
    - [ ] `ArrowLeft` — перемотка назад на 30 секунд.
    - [ ] `ArrowRight` — перемотка вперёд на 30 секунд.
    - [ ] `Shift + ArrowUp` или клавиша `>` — увеличение скорости воспроизведения.
    - [ ] `Shift + ArrowDown` или клавиша `<` — уменьшение скорости воспроизведения.
  - [ ] **Слайдер позиции воспроизведения:**
    - [ ] Имеет `role="slider"` и доступное имя `aria-label="Позиция воспроизведения"`.
    - [ ] Скринридер озвучивает текущую позицию через `getAriaValueText`: *«X минута Y секунда / Общее время: Z минута W секунда»*.
    - [ ] Клавиши `PageUp` и `PageDown` на слайдере перематывают аудиозапись соответственно на 30 секунд вперёд и назад.
    - [ ] Клавиши стрелок вправо/влево на слайдере перемещают позицию с шагом 5 секунд.
  - [ ] **Кнопки управления:**
    - [ ] Кнопка «Назад на 30 секунд» с видимой подписью и иконкой.
    - [ ] Кнопка «Предыдущий фрагмент» с видимой подписью и иконкой.
    - [ ] Центральная кнопка воспроизведения: переключает метку и иконку «Воспроизведение» / «Пауза».
    - [ ] Кнопка «Следующий фрагмент» с видимой подписью и иконкой.
    - [ ] Кнопка «Вперёд на 30 секунд» с видимой подписью и иконкой.
    - [ ] Кнопка переключения скорости: циклическое переключение (0.5x → 0.75x → 1x → 1.25x → 1.5x → 1.75x → 2x).
    - [ ] Кнопка «Добавить закладку».
    - [ ] Слайдер громкости (на экранах от sm): `aria-label="Громкость"`, значение озвучивается в процентах («70 %»).
  - [ ] **Голосовые оповещения плеера через live-регион:**
    - [ ] При смене скорости озвучивается: `«Скорость: <N>x»`.
    - [ ] При смене трека/главы озвучивается: `«Фрагмент изменён»`.
    - [ ] При добавлении закладки озвучивается: `«Закладка добавлена»`.
  - [ ] **Интеграция с Media Session API:**
    - [ ] При воспроизведении на экране блокировки мобильного устройства и на беспроводных наушниках отображаются метаданные книги (название, автор, обложка 512×512).
    - [ ] Аппаратные кнопки наушников (Play, Pause, Предыдущий/Следующий трек, перемотка) корректно управляют воспроизведением книги.
- [ ] **Вкладки информации о книге:** Вкладки «Аннотация», «Фрагменты», «Отзывы», «Рекомендации» переключают соответствующие панели `role="tabpanel"`.

### 2.4. Каталог жанров (`/genres`, `/persons/genres`, `Genres`)
- [ ] **Заголовок и крошки:** Заголовок вкладки — `Жанры — KitobPlus`, H1 — `Жанры`. Хлебные крошки: «Главная» → «Жанры».
- [ ] **Список плиток жанров:**
  - [ ] Список размечен как `<ul aria-label="Жанры" aria-busy="...">`.
  - [ ] При загрузке отображаются скелетоны высотой 112px с `borderRadius: 4`.
  - [ ] Каждая плитка жанра — это ссылка на `/person/genres/:id`.
  - [ ] Внутри плитки отображается иконка жанра (при ошибке загрузки изображения подставляется векторная иконка книги `AutoStoriesOutlined`), название жанра и счетчик аудиокниг («N книг»).
  - [ ] Плитки имеют четкое кольцо фокуса при навигации с клавиатуры.

### 2.5. Списки авторов и дикторов (`/persons/:table`, `Persons`)
- [ ] **Заголовок:** Заголовок страницы и H1 динамически меняются в зависимости от роута:
  - `/persons/authors` → `Авторы — KitobPlus`, H1: `Авторы`.
  - `/persons/dictors` → `Дикторы — KitobPlus`, H1: `Дикторы`.
- [ ] **Поиск по персонам:**
  - [ ] Форма поиска размечена как `<form role="search" aria-label="Поиск">`.
  - [ ] Текстовое поле связано с `<label htmlFor="persons-search-input">Поиск</label>`.
  - [ ] Фильтрация происходит налету по имени и биографии.
- [ ] **Список карточек (`PersonCard`):**
  - [ ] Карточки сгруппированы в `<ul aria-label="Авторы" / "Дикторы">`.
  - [ ] Фотография/аватар, имя (заголовок H2) и количество книг персоны.
  - [ ] При пустом результате поиска отображается плашка «Пусто».
