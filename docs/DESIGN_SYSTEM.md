# KitobPlus Design System (сайт)

Концепция: **«тихая современная библиотека»**. Спокойный тёплый фон, глубокий бирюзовый цвет бренда,
шафрановый акцент (отсылка к узбекскому орнаменту), крупная типографика, много воздуха.
Основная аудитория — незрячие и слабовидящие люди, поэтому доступность — часть дизайна, а не надстройка.

Код: `web/src/ds/`. Пример применения: `web/src/home/HomePage.jsx`.

## Принципы

1. **Сначала доступность.** WCAG 2.2 AA обязательно, AAA для основного текста (контраст ≥ 7:1).
2. **Одна идея на экран.** Линейная структура, предсказуемая навигация, без каруселей и автодвижения.
3. **Крупно и спокойно.** Текст от 16px, основной 18px; кнопки и цели касания от 48px; основные кнопки 56px.
4. **Иконка всегда с текстом.** Кнопок только с иконкой нет (кроме поиска и закрытия с aria-label).
5. **Цвет не единственный носитель смысла.** Статус = иконка + текст.
6. **Движение по желанию.** Все анимации отключаются при `prefers-reduced-motion`.

## Темы

Три темы, переключаются в шапке («Ko‘rinish»), сохраняются в `localStorage` (`theme_mode`):

| Тема | Фон | Текст | Акцент |
|---|---|---|---|
| light | `#F7F7F3` | `#0F1E24` (15.9:1) | primary `#0B6E79` (белый текст 6:1) |
| dark | `#0B1215` | `#EEF3F2` (16.9:1) | primary `#5CD3DD` (тёмный текст 8.8:1) |
| contrast | `#000000` | `#FFFFFF` (21:1) | `#FFE14D`, рамки вместо теней, ссылки подчёркнуты |

Размер текста: `normal` / `large` (×1.15) / `xlarge` (×1.3), через `font-size` у `html` — всё в `rem`.
Все пары цветов проверены расчётом контраста (см. коммит дизайн-системы).

Токены: `web/src/ds/tokens.js`. В компонентах брать цвета **только** из `theme.kp.p` (`const { kp } = useTheme()`),
не писать hex в компонентах.

## Типографика

- Заголовки: **Manrope Variable** 700–800, отрицательный трекинг. Текст: **Inter Variable**.
  Оба шрифта поддерживают узбекскую латиницу (oʻ, gʻ) и кириллицу, подключены локально (`@fontsource-variable`).
- `h1` — один на странице (через `PageHeader` или hero). `h2` — секции, `h3` — карточки.
- В узбекских текстах — `ʻ` (U+02BB) в oʻ/gʻ и `ʼ` для тутука.

## Отступы и формы

- Скругления: 8 / 12 / 16 / 24 / 32, кнопки и чипы — pill. В `sx` `borderRadius: N` = N × 4px.
- Секции страницы: `py: { xs: 7, md: 11 }`. Контейнер `Container`: макс. 1240px, поля 16/24px.
- Тени мягкие многослойные (`kp.shadows.card | raised | float`); в контрастной теме теней нет — рамки.

## Компоненты (`web/src/ds/components/`)

| Компонент | Назначение |
|---|---|
| `PageShell` | Каркас страницы: skip-link, шапка, `<main id="main_content">`, подвал, заголовок вкладки и фокус при смене страницы. **Каждая страница оборачивается в него.** |
| `PageHeader` | Шапка внутренней страницы: хлебные крошки, H1, подзаголовок, действия. |
| `SectionHeader` | Заголовок секции + ссылка «Все …». |
| `Container` | Ширина контента. |
| `SiteHeader` / `SiteFooter` | Шапка (меню, поиск, «Вид», язык, вход) и подвал. Мобильное меню — Drawer. |
| `BookCard`, `BookGrid`, `BookCardSkeleton` | Карточка книги (ссылка на названии растянута на карточку), адаптивная сетка 2→6 колонок, скелетоны загрузки. |
| `BookCover` | Обложка 2:3; без картинки — сгенерированная обложка с названием. |
| `Logo`, `LogoMark` | Знак: раскрытая книга + звуковая волна. |
| `DisplaySettingsMenu`, `LanguageMenu` | Тема/размер текста; язык. |

Форматирование длительности: `useFormatDuration()` из `ds/format.js` («10 soat 20 daqiqa»).

## Правила для страниц

- Тексты только через `T('<русский текст>')`, перевод — в `web/src/lib/translation.json` (`UZ`, `US`).
- Списки карточек — `<ul>/<li>`; у списков и секций — `aria-label`/`aria-labelledby`.
- Ссылка = переход, кнопка = действие. Карточка — одна ссылка (на названии).
- Состояния: загрузка — скелетоны с `aria-busy`, пусто — понятный текст и действие, ошибка — `role="alert"`.
- Формы: видимая подпись (`label`), подсказка и ошибка через `aria-describedby`, поле 56px.
- Не ломать уже сделанную доступность: `lib/a11y.js` (`announce`, `VisuallyHidden`, `useRouteA11y`),
  клавиатура и Media Session в плеере, `getPaginationItemAriaLabel`.
