# KitobPlus Design System (сайт)

Стиль: **«A+D» — минимализм концепции «Живой голос» и акценты «Литературного журнала»**.
Центральный образ — живой звук книги: крупный центрированный заголовок героя, «дышащая» звуковая волна, кнопка мгновенного прослушивания 10 секунд отрывка книги дня, анимированный логотип-эквалайзер («книга, которая звучит») и бесшовный переход «обложка летит на страницу книги» (View Transitions API). Журнальный характер выражен акцентными словами курсивом с засечками (`Accent`), редакторской сеткой полок, жанров и новостей.

Основная аудитория библиотеки — незрячие и слабовидящие пользователи Узбекистана, поэтому доступность (accessibility) — фундаментальная основа каждого компонента и дизайн-решения.

Код дизайн-системы: `web/src/ds/`.
Токены: `web/src/ds/tokens.js`.
Темизация: `web/src/ds/theme.js`.
Шрифты: `web/src/ds/fonts.js`.
Анимация: `web/src/ds/motion.jsx`.
Компоненты: `web/src/ds/components/`.
Пример применения: `web/src/home/HomePage.jsx`.

## 1. Принципы

1. **Сначала доступность (Accessibility First).** WCAG 2.2 AA обязательно, AAA для основного текста (контраст ≥ 7:1) и не ниже 4.5:1 для вспомогательных элементов во всех трёх темах. Все интерактивные элементы имеют доступные подписи и фокус-видимость.
2. **Живой голос и спокойный минимализм.** Линейная, предсказуемая структура страниц без навязчивого автодвижения, без каруселей. Фокус на содержании книги, дикторах и звуке.
3. **Крупно, читаемо и пропорционально.** Базовый размер шрифта от 16px, основной текст 18px (1.125rem); минимальная высота кнопок и полей ввода — 48px, основные кнопки и инпуты — 56px.
4. **Иконка всегда поддержана текстом.** Элементов управления только с иконкой без подписи нет. Иконки сопровождаются видимым текстом или явным `aria-label` / `VisuallyHidden`.
5. **Цвет не единственный носитель смысла.** Статусы, активность вкладок и состояния дублируются текстом, иконками, подчеркиванием или рамками (особенно важно в высококонтрастной теме).
6. **Движение по согласию пользователя.** Все анимации (волны, появление блоков, подъем заголовка, View Transitions) полностью отключаются при системной настройке `prefers-reduced-motion: reduce`.
7. **Отказоустойчивость.** Если обложка или аудиоотрывок недоступны, всегда есть аккуратная альтернатива: сгенерированная векторная обложка или чтение названия через браузерный SpeechSynthesis.

## 2. Темы и цвета

В системе три темы. Переключаются в меню «Вид» (`DisplaySettingsMenu` / `DisplaySettingsPanel`) в шапке сайта, сохраняются в `localStorage` (ключ `theme_mode`):

| Тема | Фон (`bg`) | Поверхность (`surface`) | Текст (`text`) | Основная кнопка (`action` / `onAction`) | Акцент бренда (`primary`) |
|---|---|---|---|---|---|
| **light** | `#FBFBF9` (тёплый белый) | `#FFFFFF` | `#0E1A2B` (контраст 16.5:1) | `#0E1A2B` («чернила», текст `#FFFFFF` 16:1) | `#1D5FA8` («Moviy», белый текст 6.4:1) |
| **dark** | `#0A1019` | `#111A26` | `#EEF2F8` (контраст 17:1) | `#EEF2F8`, текст `#0A1019` | `#8CC2F5` (тёмный текст 8.9:1) |
| **contrast** | `#000000` | `#000000` | `#FFFFFF` (контраст 21:1) | `#FFE14D`, текст `#000000` | `#FFE14D`, рамки вместо теней, ссылки с подчеркиванием |

> [!NOTE]
> **Иерархия цветов стиля «A+D»:**
> - Основные действия (`action` / `onAction`): кнопки первичного действия окрашены в глубокий «чернильный» цвет (`#0E1A2B` в светлой теме, `#EEF2F8` в тёмной), обеспечивая максимальный контраст 16:1.
> - Цвет «Moviy» (`#1D5FA8` в светлой, `#8CC2F5` в тёмной) выступает исключительно **фирменным акцентом**: индикаторы активных вкладок, кольцо фокуса, акцентные слова, ссылки, логотип, вторичные бейджи.
> - Шафрановый акцент (`accent`: `#F2B33D` / `#F5BE55`, `onAccent`: `#1C1404`): используется только с тёмным текстом.
> - Тёмные секции и плашки (`ink`: `#0D1726`, `onInk`: `#F2F5F9`, `cyan`: `#7DB8F2`).
> - Рамки полей ввода и кнопок (`borderStrong`: `#6E7B8C` в светлой теме) соответствуют WCAG 1.4.11 (контраст графических границ ≥ 3:1).

### Палитра сгенерированных обложек (`coverGradients`)
Если у книги отсутствует изображение обложки, генерируется декоративный 2-цветный градиент с контрастным белым текстом (`#FFFFFF`). Все 8 предустановленных пар цветов проходят норматив 4.5:1:
1. `["#1D5FA8", "#0F2F57", "#FFFFFF"]`
2. `["#7A3E9D", "#3A1F55", "#FFFFFF"]`
3. `["#B4532A", "#5A2410", "#FFFFFF"]`
4. `["#1F6F4A", "#0E3524", "#FFFFFF"]`
5. `["#2B4C9B", "#14234D", "#FFFFFF"]`
6. `["#8A6A12", "#3D2E05", "#FFFFFF"]`
7. `["#9B2F4E", "#4A1424", "#FFFFFF"]`
8. `["#3B5560", "#17252B", "#FFFFFF"]`

### Тени и границы
- Скругления (`radii`): `xs: 8`, `sm: 12`, `md: 16`, `lg: 24`, `xl: 32`, `pill: 999`. В MUI `shape.borderRadius = 4` (в `sx` `borderRadius: N` = N × 4px).
- Тени (`shadows(p)`):
  - `light`: мягкие многослойные `card`, `raised`, `float`.
  - `dark`: затемнённые рассеянные тени `card`, `raised`, `float`.
  - `contrast`: теней нет (`none`), вместо теней используются контрастные рамки `border` / `borderStrong` (толщиной 1.5–2px).
- Фокус (`focusRing`): `outline: 3px solid ${p.focus}`, `outlineOffset: 3`, `boxShadow: 0 0 0 6px ${p.focusHalo}`.

### Правило работы с цветами в коде
В компонентах запрещено хардкодить hex-значения. Цвета берутся **только** из темы:
```javascript
const { kp } = useTheme();
// Использование: kp.p.text, kp.p.primary, kp.p.action, kp.p.border, kp.shadows.card
```

## 3. Типографика и масштабы текста

### Шрифты (`web/src/ds/tokens.js`, `web/src/ds/fonts.js`)
Все шрифты подключены локально через npm-пакеты `@fontsource`, без внешних HTTP-запросов к сторонним сервисам:
1. **Заголовки (`fonts.heading`):** `'Inter Tight Variable', 'Inter Variable', system-ui, sans-serif`.
   - Жирность: 700–800.
   - Отрицательный трекинг: от `-0.02em` до `-0.058em` для плотного журнального вида.
   - Плавный адаптивный размер `clamp(...)`: H1 от 2.75rem до 5.5rem (на главной — до 10rem).
2. **Основной текст и интерфейс (`fonts.body`):** `'Inter Variable', 'Inter', system-ui, -apple-system, 'Segoe UI', Roboto, sans-serif`.
   - Используется для параграфов (`body1`, `body2`), элементов списков, кнопок, подписей полей.
   - Особенности рендеринга: `fontFeatureSettings: "'cv11', 'ss01'"`, сглаживание текста.
3. **Акцентные слова (`fonts.serif`):** `'Instrument Serif', 'Georgia', 'Times New Roman', serif`.
   - Применяется внутри компонента `<Accent>` для ключевых слов в заголовках: наклонное начертание (курсив), засечки, размер `1.06em`.
   - В шрифте Instrument Serif нет кириллического диапазона — для текстов на русском языке автоматически подставляется системный serif-курсив (Georgia).

### Узбекская типографика
Шрифты Inter и Inter Tight полноценно поддерживают узбекский латинский алфавит и кириллицу. В коде и переводах строго соблюдаются типографические стандарты:
- Буквы **oʻ** и **gʻ** оформляются через модификатор буквы перевёрнутый апостроф: `ʻ` (`U+02BB`).
- Разделительный твёрдый знак (тутук белгиси) оформляется через типографский апостроф: `ʼ` (`U+02BC` или `U+2019`). Обычный машинописный апостроф `'` не используется в текстах интерфейса.

### Масштабирование текста (`textScales`)
Пользователь может изменить размер текста в меню «Вид». Значение масштабирует базовый размер шрифта через корневой `html { font-size: ${100 * scale}% }`:
- `normal`: 1.0 (базовый 16px; `body1` = 18px / 1.125rem).
- `large`: 1.15 (базовый 18.4px; увеличение на 15%).
- `xlarge`: 1.3 (базовый 20.8px; увеличение на 30%).

Так как все размеры отступов, компонентов и типографики в дизайн-системе заданы в относительных единицах (`rem`), вся страница масштабируется пропорционально без поломки вёрстки.

## 4. Движение и анимации (Motion)

Все анимации собраны в модуле `web/src/ds/motion.jsx`. Главное правило доступности: **при `prefers-reduced-motion: reduce` все анимации отключаются (duration = 0.01ms / animation: none)**.

### Компоненты анимации
- `<Reveal as="div" delay={0} y={28} sx={...}>`:
  - Плавное появление блока со сдвигом вверх при прокрутке страницы.
  - Реализован через `IntersectionObserver` с порогом `threshold: 0.12`.
  - **Доступность:** содержимое всегда присутствует в DOM; скринридеры видят его сразу, не дожидаясь скролла. При `reduced motion` компонент рендерится сразу в конечном состоянии (`opacity: 1, transform: none`).
- `<RiseText lines={[[...], [...]]} delay={0} step={0.12}>`:
  - Редакторский заголовок, строки и слова которого плавно поднимаются из-за границы маски (`kpRise 1s cubic-bezier(.2,.8,.2,1)`).
  - **Доступность:** для скринридеров текст не дробится на фрагменты и читается как единая фраза.
- `<Accent color={...}>`:
  - Стилизует акцентное слово внутри заголовка в стиле концепции D (`Instrument Serif`, курсив, цвет `primary` по умолчанию).

### Переход «обложка летит на страницу книги» (View Transitions)
При клике на карточку книги обложка плавно трансформируется и перемещается на место обложки на странице книги:
1. `coverTransitionName(id)`: возвращает строковый идентификатор вида `kp-cover-${id}`.
2. `navigateWithTransition(navigate, to, sourceEl, id, state)`:
   - Проверяет поддержку `document.startViewTransition` и отсутствие `prefersReducedMotion()`. Если проверка не пройдена — выполняется обычный переход `navigate()`.
   - Присваивает `sourceEl.style.viewTransitionName = coverTransitionName(id)`.
   - Внутри колбэка перехода `document.startViewTransition` синхронно обновляет роут через `flushSync(go)` и сбрасывает скролл `window.scrollTo({ top: 0, left: 0, behavior: "instant" })`, чтобы снимок новой страницы строился уже с верхней точки.
   - Передает `state.book` для мгновенной отрисовки шапки и обложки на странице книги до завершения сетевых запросов.
   - По завершении перехода (`t.finished.finally`) очищает `viewTransitionName`.
3. **Тайминги в теме (`theme.js`):**
   - `::view-transition-group(*)`: `animationDuration: "0.6s"`, функция `cubic-bezier(.2,.8,.2,1)`.
   - `::view-transition-old(root), ::view-transition-new(root)`: короткий cross-fade длительностью `0.32s`.

## 5. Компоненты дизайн-системы (`web/src/ds/components/`)

### `PageShell`
Главный каркас любой страницы библиотеки. Каждая страница обязательно оборачивается в `PageShell`.
- **Свойства (Props):**
  - `title` *(string, обязательный)*: Название страницы. Передается в `useRouteA11y(title)` — обновляет `document.title` в формате `«<title> — KitobPlus»` и переносит фокус в `<main id="main_content">` при переходах.
  - `children` *(ReactNode)*: Содержимое страницы.
- **Что включает в себя:**
  - Скрытая ссылка для быстрого перехода: `<a className="kp-skip-link" href="#main_content">` (появляется по Tab).
  - Скринридерный live-регион `<Announcer />` (`#a11y-announcer`).
  - Шапка `<SiteHeader />`.
  - Основной ориентир: `<Box component="main" id="main_content" tabIndex={-1}>`.
  - Подвал `<SiteFooter />`.

### `PageHeader`
Стандартизированная шапка внутренней страницы (каталог, авторы, жанры, новости, контакты, профиль).
- **Свойства (Props):**
  - `title` *(ReactNode / string, обязательный)*: Заголовок страницы уровня H1.
  - `subtitle` *(ReactNode / string, опционально)*: Поясняющий подзаголовок или статистика (например, «Найдено книг: 120»).
  - `crumbs` *(Array<{ label: string, to?: string }>, по умолчанию `[]`)*: Массив элементов хлебных крошек. Ссылка на «Главную» добавляется автоматически первой. Текущая страница отмечается `aria-current="page"`.
  - `actions` *(ReactNode, опционально)*: Кнопки действий справа от заголовка.
  - `eyebrow` *(string, опционально)*: Надзаголовочный текст (MUI `overline`).
- Анимация: заголовок и подзаголовок плавно поднимаются через `<Reveal y={18}>`.

### `SectionHeader`
Заголовок логической секции на странице.
- **Свойства (Props):**
  - `title` *(ReactNode / string, обязательный)*: Текст заголовка (обычно H2, можно использовать `<Accent>`).
  - `id` *(string, опционально)*: HTML ID для связывания через `aria-labelledby` с секцией или табпанелью.
  - `subtitle` *(ReactNode / string, опционально)*: Поясняющий текст.
  - `linkTo` *(string, опционально)*: Путь для ссылки «Все …» (например, `/books`).
  - `linkLabel` *(string, опционально)*: Текст ссылки («Все книги», «Все жанры»).
  - `level` *(string, по умолчанию `"h2"`)*: Семантический уровень заголовка (`"h2"`, `"h3"`).

### `BookCard` и `BookCardSkeleton`
Карточка аудиокниги.
- **Свойства `BookCard` (Props):**
  - `book` *(Object, обязательный)*: Данные книги (`id`, `title`, `authors_name`, `dictors_name`, `seconds`, `pics_ext`, `rate`).
  - `headingLevel` *(string, по умолчанию `"h3"`)*: Уровень заголовка названия.
  - `eager` *(boolean, по умолчанию `false`)*: Приоритетная загрузка картинки обложки (для первых карточек на экране).
- **Особенности доступности и верстки:**
  - Корневой тег — `<article>`.
  - **Правило одной ссылки:** ссылка перехода расположена на названии книги, а через псевдоэлемент `&::after { content: '""', position: "absolute", inset: 0, zIndex: 1 }` растянута на всю площадь карточки. Экранная читалка озвучивает ровно одну понятную ссылку, избегая дублирования.
  - Клик запускает бесшовный переход с сохранением состояния через `navigateWithTransition`.
  - Длительность форматируется через локализованный `useFormatDuration(book.seconds)`.
  - Имя диктора сопровождается скрытой подписью для скринридера: `<VisuallyHidden>Читает: </VisuallyHidden>`.
  - При фокусе с клавиатуры на карточке рисуется контурное кольцо: `&:focus-within { outline: 3px solid ${kp.p.focus} }`.
- **`BookCardSkeleton`**: скелетон заглушки с `aria-hidden="true"` (обложка с пропорциями 2:3, две строки текста).

### `BookGrid`
Адаптивная сетка карточек книг.
- **Свойства (Props):**
  - `books` *(Array<Object>)*: Список книг.
  - `loading` *(boolean)*: Флаг загрузки (отображает скелетоны).
  - `count` *(number, по умолчанию `5`)*: Количество отображаемых скелетонов при загрузке.
  - `columns` *(Object, по умолчанию `{ xs: 2, sm: 3, md: 4, lg: 5 }`)*: Число колонок по брейкпоинтам.
  - `headingLevel` *(string, по умолчанию `"h3"`)*: Семантический уровень заголовка карточки.
  - `label` *(string, опционально)*: Значение `aria-label` для списка.
- **Семантика:** рендерится как семантический список `<Box component="ul" aria-label={label} aria-busy={loading ? "true" : undefined}>`. Каждый элемент — `<li>`, оборачивается в `<Reveal as="li" delay={(i % 6) * 0.07}>` для каскадного появления.

### `BookCover`
Компонент обложки книги с фиксированным соотношением сторон 2:3.
- **Свойства (Props):**
  - `book` *(Object)*: Данные книги (используются `id`, `title`, `authors_name`, `pics_ext`).
  - `rounded` *(number, по умолчанию `16`)*: Радиус скругления в пикселях.
  - `eager` *(boolean, по умолчанию `false`)*: Атрибут `loading="eager"` для ускорения отрисовки LCP.
  - `transitionName` *(string, опционально)*: Имя View Transition (`coverTransitionName(id)`).
  - `className`, `sx`: Дополнительные классы и стили MUI.
- **Отказоустойчивость:** Обложка помечена `alt=""` как декоративная (название книги уже присутствует в ссылке карточки). Если картинка не найдена или не загрузилась (`onError`), компонент автоматически отображает стилизованную векторную обложку: уникальный градиент из `coverGradients`, 11-полосный эквалайзер, крупное название книги (до 4 строк) и имя автора.

### `SiteHeader`
Шапка сайта с двухуровневой адаптивностью под масштабирование текста.
- При увеличении масштаба текста (`large` / `xlarge`) меню автоматически переключается на компактную кнопку «Меню» раньше обычного (`(min-width: ${1280 * scale}px)`).
- Включает логотип, горизонтальное меню с индикатором `aria-current="page"`, кнопку быстрого поиска книг, меню «Вид», меню языка и кнопки входа/профиля.
- Мобильное меню реализовано через доступный `Drawer` с фокус-ловушкой, кнопкой закрытия, дублированием всех разделов, панелью настроек вида и кнопками смены языка.

### `SiteFooter`
Информационный подвал сайта.
- Темная секция (`kp.p.ink`, текст `kp.p.onInk`).
- Инвертированный логотип `Logo inverted`.
- Прямые ссылки на мобильные приложения KitobPlus в App Store и Google Play.
- Ссылки на разделы библиотеки, страницу «О нас», новости, профиль, контакты.
- Контактные ссылки с семантическими протоколами `mailto:` и `tel:`.
- Информация об авторских правах и партнерстве с Обществом инвалидов «ШароитПлюс».

### `HeaderMenus` (модуль меню шапки)
- `LANGUAGES`: список доступных языков (UZ, RU, US).
- `useLanguage()`: хук выбора и сохранения языка сайта.
- `LanguageMenu({ compact })`: меню переключения языка с индикацией текущего (`CheckIcon`, `aria-current="true"`).
- `DisplaySettingsMenu()`: кнопка «Вид», открывающая доступный Popover (`role="dialog"`, `aria-labelledby="kp-display-title"`).
- `DisplaySettingsPanel()`: панель выбора темы (светлая / тёмная / контрастная) и размера шрифта (обычный / крупный / очень крупный) на базе `ToggleButtonGroup`. При изменении параметров отправляет голосовое уведомление скринридеру через `announce()`.

### `Logo` и `LogoMark`
- `LogoMark({ size = 22, inverted = false, animated = true })`: фирменный знак — четыре столбика эквалайзера с непрерывной плавной анимацией (`kpEq`). При `prefers-reduced-motion` анимация отключается.
- `Logo({ inverted = false, to = "/" })`: ссылка на главную страницу с обязательным атрибутом `aria-label="KitobPlus — главная страница"`.

### `Container`
Универсальный ограничитель ширины страницы (`maxWidth: 1240 + 48` = 1288px) с адаптивными безопасными отступами по бокам: `px: { xs: 2, sm: 3 }` (16px на мобильных, 24px на десктопе).

## 6. Правила переводов и локализация

В репозитории KitobPlus базовым языком разработки и ключами словаря является **русский язык** (`RU`). Переводы на узбекский (`UZ`) и английский (`US`) хранятся в `web/src/lib/translation.json`.

### Железное правило: `T()` против `tr()`
В кодовой базе строго разграничены две функции перевода из `web/src/lib/translator.js`:

```javascript
import T, { tr } from "../lib/translator";
```

1. **`T(key)` — ТОЛЬКО во время рендера компонентов:**
   - Вызывается внутри тела функционального компонента или прямо в JSX.
   - Под капотом вызывает хук `useLibrary().countryCode`, подписывая компонент на контекст библиотеки. При смене языка пользователем в шапке весь интерфейс мгновенно перерисовывается без перезагрузки страницы.
   - Запрещено вызывать вне рендера (в утилитах, обработчиках, промисах).

2. **`tr(key, [countryCode])` — в обработчиках событий, эффектах и асинхронных функциях:**
   - Вызывается внутри `onClick`, `onChange`, `onSubmit`, `setTimeout`, таймеров плеера, обработчиков `useEffect`, а также при вызове речевых оповещений `announce(...)`.
   - В этих местах вызов хуков React запрещен правилами хуков. `tr()` считывает сохранённый в `localStorage` код страны напрямую через `getCountryCode()` и возвращает переведённую строку.

## 7. Правила разработки страниц

1. **Семантика и структура:**
   - На странице должен быть ровно один заголовок `<h1>` (задаётся через `PageHeader` или hero главной страницы).
   - Заголовки секций — `<h2>`, заголовки карточек — `<h3>`.
   - Навигационные блоки размечаются `<nav aria-label="...">`.
   - Списки карточек, ссылок и категорий обязательно верстаются через `<ul>` и `<li>` с указанием `aria-label` или `aria-labelledby`.
2. **Ссылки и кнопки:**
   - Ссылка (`<a>` / `RouterLink`) используется **только** для перехода на другой URL.
   - Кнопка (`<button>` / `Button`) используется **только** для действий на текущей странице (воспроизведение, переключение вкладок, открытие модалок, отправка форм).
3. **Клавиатурная доступность:**
   - Интерактивные элементы должны быть доступны по клавише Tab.
   - Порядок фокуса логичный и предсказуемый.
   - Кольцо фокуса (`:focus-visible`) никогда не убирается через `outline: none` без предоставления доступной альтернативы из темы (`kp.focusRing`).
4. **Состояния интерфейса:**
   - **Загрузка:** отображаются скелетоны (`Skeleton`), родительский контейнер помечается `aria-busy="true"`.
   - **Ошибка:** отображается понятный текст сообщения в блоке с `role="alert"` (MUI `Alert severity="error"`) с кнопкой повтора действия.
   - **Пусто:** информативное сообщение о том, что данных нет, и кнопка сброса фильтров или перехода в каталог.
5. **Формы:**
   - Каждое поле имеет видимый `<label htmlFor="...">`.
   - Ошибки валидации и подсказки связываются с полем через `aria-describedby`.
   - Минимальная высота полей ввода — 56px (`radii.md`, рамка `borderStrong`).

## 8. Как сделать новую страницу (чеклист и шаблон)

### Чеклист
- [ ] Страница импортирует и возвращает `PageShell` с заголовком в `T()`.
- [ ] Добавлен `PageHeader` с хлебными крошками `crumbs` и H1.
- [ ] Контент обёрнут в `<Container>`.
- [ ] Все тексты интерфейса обёрнуты в `T(...)`, а строки в обработчиках/алертах — в `tr(...)`.
- [ ] Все цвета берутся из `useTheme().kp.p`, шрифты — из `kp.fonts`.
- [ ] Реализованы 3 состояния: загрузка (скелетоны), ошибка (`role="alert"`), пусто.
- [ ] Добавлены секции с заголовками H2 (`SectionHeader` или `Typography component="h2"`).
- [ ] Проверено отсутствие каруселей и горизонтального скролла на экранах 320–390px.
- [ ] Все анимации используют `<Reveal>` и отключаются при `prefers-reduced-motion`.

### Шаблон кода страницы

```jsx
import React, { useState } from "react";
import { Box, Typography, Button, Alert, useTheme } from "@mui/material";
import useSWR from "swr";
import PageShell, { PageHeader, SectionHeader } from "../ds/components/PageShell";
import Container from "../ds/components/Container";
import { BookGrid } from "../ds/components/BookCard";
import { Reveal } from "../ds/motion";
import { getHost } from "../lib/api";
import { announce } from "../lib/a11y";
import T, { tr } from "../lib/translator";

const fetchJson = (url) => fetch(url).then((res) => res.json());

const SamplePage = () => {
  const { kp } = useTheme();
  const [filter, setFilter] = useState("all");

  const { data, error, isLoading, mutate } = useSWR(
    `${getHost()}/srv/books.php?filter=${filter}`,
    fetchJson
  );

  const handleAction = () => {
    // Внутри обработчиков используем tr(), а не T()
    announce(tr("Фильтр обновлен"));
    mutate();
  };

  return (
    <PageShell title={T("Новый раздел")}>
      <PageHeader
        title={T("Новый раздел")}
        subtitle={T("Описание назначения раздела библиотеки")}
        crumbs={[{ label: T("Новый раздел") }]}
      />

      <Container sx={{ py: { xs: 4, md: 7 } }}>

          <Alert
            role="alert"
            severity="error"
            action={<Button color="inherit" onClick={() => mutate()}>{T("Обновить")}</Button>}
            sx={{ mb: 4 }}
          >
            {T("Не удалось загрузить данные")}
          </Alert>
        ) : (
          <section aria-labelledby="sample-section-title">
            <SectionHeader
              id="sample-section-title"
              title={T("Рекомендуемые книги")}
              linkTo="/books"
              linkLabel={T("Все книги")}
            />

              books={data && data.data}
              loading={isLoading}
              count={4}
              columns={{ xs: 2, sm: 2, md: 4, lg: 4 }}
              label={T("Рекомендуемые книги")}
            />
          </section>
        )}
      </Container>
    </PageShell>
  );
};

export default SamplePage;
```
