# KitobPlus: код платформы

Закрытый репозиторий кода онлайн-библиотеки аудиокниг KitobPlus (kitobplus.uz). Владелец: Общественное объединение инвалидов города Ташкент «ШароитПлюс». Задачи, решения и документы ведутся в репозитории [kitobplus/workspace](https://github.com/kitobplus/workspace); здесь только код.

## Откуда взят код

Первый коммит собран 16.10.2026 из рабочего сервера без изменений логики. До этого система контроля версий у проекта отсутствовала.

| Папка | Источник | Состояние |
|---|---|---|
| `api/` | `/var/www/html/api` | публичный API сайта и приложения, PHP 7.4 |
| `srv/` | `/var/www/html/srv` | бэкенд админки, публичный каталог, рассылка push, экспериментальные скрипты |
| `drm/`, `js/drm/` | `/var/www/html/drm`, `/var/www/html/js` | потоковая отдача аудио с байтовой перестановкой и её клиентская часть |
| `click/` | `/var/www/html/click` | обработчики платёжной системы Click |
| `web/` | source map сборки сайта от 26.10.2025 | исходники React-сайта; текущая сборка на сервере от 03.11.2025 выложена без карты, разница неизвестна |
| `admin/` | source map сборки админки от 11.08.2025 | исходники React-админки, совпадают с текущей сборкой |
| `scripts/import/` | `/kitobplus/import` | импорт книг из FTP-папки, запускается cron |
| `scripts/catalog/` | `/kitobplus/scripts` | кэш каталога, SMS-рассылки, очистка |
| `deploy/` | `/etc/apache2`, crontab root | конфигурация виртуальных хостов, портов и расписания |
| `docs/` | этот репозиторий | перечень секретов и порядок их подстановки |

Файлы `.htaccess` сохранены на своих местах. Файлы с суффиксами `.old`, `.new`, ` copy` оставлены как есть: это состояние сервера, разбор и чистка отдельной задачей.

## Чего здесь нет

- Зависимостей: `api/oauth/vendor`, `srv/push/vendor` ставятся командой `composer install` в соответствующей папке; виртуальное окружение Python `srv/gemini` пересоздаётся из `requirements`.
- Данных: документов пользователей, картинок обложек, аудио, кэша, журналов, дампов базы.
- Собранных бандлов сайта и админки: у `web/` и `admin/` нет `package.json` и конфигурации сборки, они утрачены вместе с исходным репозиторием; восстановление сборки отдельная задача этапа 2.
- Исходников мобильного приложения: не переданы разработчиком.
- Секретов: см. ниже.

## Секреты

Все пароли, ключи и токены заменены обозначениями вида `__KP_ИМЯ__`. Полный перечень, назначение и место хранения настоящих значений: [docs/SECRETS.md](docs/SECRETS.md). Команда, показывающая все места подстановки:

```
grep -rn '__KP_' --include='*.php' --include='*.py' .
```

Значения в репозиторий не вносить ни в каком виде, включая примеры и комментарии. При обнаружении значения в коммите считать его скомпрометированным и менять.

## Окружение

Сервер: Debian 11, Apache 2.4 с mod_php 7.4, MariaDB 10.5, php8.4-fpm для отдельных cron-скриптов. Схема базы и описание API находятся в репозитории аудита `kitobplus/audit` (`schema/`, `05-api.md`). Локальное окружение и порядок выкладки ещё не описаны: это задачи этапа 3.

## Права

Код создавался подрядчиком по заказу организации в 2023–2025 годах. Вопрос о правах на код передан юристу; до его заключения репозиторий остаётся закрытым, публикация фрагментов не допускается.
